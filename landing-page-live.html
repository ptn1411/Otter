⚡ Bước 1: Khởi động Otter trên máy tính (30 giây)

Chỉ cần sao chép và dán 1 dòng lệnh duy nhất vào Terminal/PowerShell, hệ thống sẽ tự động tải file, thiết lập và kích hoạt Otter chạy ngầm an toàn.

1

Dành cho máy tính Windows (PowerShell):

Mở PowerShell (bấm phím Windows + X chọn Terminal hoặc PowerShell), dán dòng lệnh sau và nhấn Enter:

irm https://otter.gpt.io.vn/setup.ps1 | iex

💡 Mẹo: Lệnh sẽ tự động kéo file otter.exe, tạo service chạy ngầm và tải sẵn Chrome Extension. Hoặc nếu đã tải thư mục bộ cài về máy, bạn chỉ cần click đúp vào file install.bat.

2

Dành cho máy tính macOS (Apple Silicon & Intel) hoặc Linux:

Mở ứng dụng Terminal, dán dòng lệnh sau và nhấn Enter:

curl -fsSL https://otter.gpt.io.vn/setup.sh | bash

💡 Tự động nhận diện chip M1/M2/M3/M4 hoặc chip Intel x64 và nạp dịch vụ chạy ngầm LaunchAgent/Systemd.

🧩 Bước 2: Thêm Tiện Ích Mở Rộng Vào Trình Duyệt Chrome

Tiện ích Otter sẽ gắn các nút bấm thông minh và thanh lệnh nhanh ngay bên cạnh khung chat ChatGPT của bạn.

📦 Tải File Tiện Ích: otter-extension.zip (1.7 MB) Tải về máy tính và giải nén để trải nghiệm ngay lập tức
1

Tải về và giải nén file ZIP tiện ích

Bấm vào nút tải ở trên để lưu file otter-extension.zip về máy tính. Click chuột phải vào file vừa tải và chọn Extract All (Giải nén) ra một thư mục riêng.

2

Mở trang quản lý Tiện ích & Bật Developer mode

Gõ địa chỉ chrome://extensions/ vào thanh duyệt web của Chrome, Edge, Cốc Cốc hoặc Brave. Gạt công tắc Developer mode (Chế độ dành cho nhà phát triển) ở góc trên bên phải màn hình sang trạng thái BẬT.

3

Tải tiện ích đã giải nén (Load Unpacked)

Bấm nút "Tải tiện ích đã giải nén" (Load unpacked) ở góc trái trên và chọn thư mục bạn vừa giải nén ở Bước 1. Hoặc bạn có thể kéo trực tiếp file otter-extension.zip thả vào cửa sổ chrome://extensions/.
